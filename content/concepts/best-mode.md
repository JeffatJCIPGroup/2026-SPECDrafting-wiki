# Best Mode（最佳模式）

## 定義

Best mode 是 [[statute-35usc112|35 U.S.C. §112]] 第一段的要求之一：說明書必須揭露發明人在申請日當時**主觀上認為**實施其發明的最佳方式。

## 詳細說明

### Sheldon 的 14 條操作指引（§7.4.2）

1. **僅適用於請求標的及必要的未請求標的**：未請求的周邊技術（如製造設備）原則上不需揭露
2. **以申請日當時為準**：只需揭露申請日當時已知的最佳模式，申請後發現的改進不受此要求約束
3. **不必然是最終商業方法**：Best mode 不需要是最終產品化的方法，只需是申請當時發明人認為最佳的方法
4. **以發明人的主觀認知為準**：即使客觀上有更好的方法，只要發明人主觀上認為某方法最佳，即滿足要求
5. **違反可能是偶然的**：遺忘揭露某個關鍵參數也構成違反，不需要有意圖
6. **必須揭露，即使發明人未發明它**：若最佳模式使用了第三方技術，也必須揭露（可能有商業秘密與 best mode 衝突的問題）
7. **揭露必須客觀上可實施（objectively enabling）**：僅宣稱存在最佳模式而不揭露細節是不夠的
8. **使用商標揭露最佳模式的問題**：以商標名稱（如 "Teflon"）揭露最佳模式有風險，因為商標所指的具體成分可能隨時間改變
9. **不可依賴非常規先前技術**：若最佳模式依賴於非常規、非廣泛可得的先前技術，需在說明書中揭露
10. **無需標示，但不可隱藏**：說明書無需明確標示哪個是 "best mode"，但不可故意隱藏
11. **不可誤導公眾**：不可在說明書中積極誤導公眾認為非最佳模式才是最佳的
12. **Working example 是最有效的揭露方式**：包含數據的 working example 是揭露 best mode 最清楚的方式
13. **Trade secrets 與 best mode 不相容**：若最佳模式包含商業秘密，申請人面臨兩難——揭露則失去商業秘密保護，不揭露則違反 best mode 要求
14. **Best mode 不包括未請求的用途**：若發明有多種用途，只請求其中一種，best mode 只需針對被請求的用途

### 重要實務風險

- **Trade secret 困境**：製造工藝常是商業秘密，若發明的最佳實施方式涉及專有製造工藝，必須在申請書中揭露，這意味著放棄商業秘密保護
- **違反後果**：Best mode 違反可導致專利無效，且在訴訟中難以辯護（因為是主觀標準）

## 實務要點

1. 在訪談發明人時，明確詢問：「你認為目前實施這個發明的最佳方式是什麼？」
2. 特別注意隱藏的最佳模式（如特定廠商的材料、特定製造條件）
3. Working example 應包含發明人認為最佳的具體參數
4. 若客戶有相關商業秘密，事先討論揭露的必要性與策略
